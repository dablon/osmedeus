# Osmedeus Core Engine

Osmedeus is a Workflow Engine for Offensive Security designed to build a foundation with the capability and flexibility that allows you to build your own reconnaissance system and run it on a large number of targets.

## Key Features
- Significantly speed up reconnaissance processes
- Organize scan results efficiently
- Customize and optimize recon workflows
- Seamlessly integrate with public and private security tools
- Scale across large numbers of targets
- Synchronize results across multiple locations

## Target Use Cases
- Automated security reconnaissance
- Vulnerability scanning workflows
- Large-scale target enumeration
- Offensive security testing automation
- Custom security tool orchestration

The engine supports various scan types including subdomain enumeration, port scanning, vulnerability detection, directory brute-forcing, and cloud asset discovery through modular YAML-based workflows.
